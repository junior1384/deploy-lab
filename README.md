Primeiro Laboratório de Deploy

Este laboratório demonstra um processo de deploy automatizado utilizando GitHub Actions e um servidor Linux.

A primeira configuração do servidor é realizada manualmente, incluindo a preparação da infraestrutura necessária para executar a aplicação.

Após essa configuração inicial, o processo de deploy é automatizado, permitindo:

Deploy da aplicação;
Separação entre ambientes de Homologação e Produção;
Controle das versões implantadas;
Manutenção de versões anteriores;
Rollback para uma versão anterior caso um deploy apresente problemas.

O objetivo deste primeiro laboratório é demonstrar os conceitos fundamentais de CI/CD, deploy automatizado, versionamento de releases e rollback.
